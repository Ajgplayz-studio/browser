What is this browser?

This browser doesn't surf the whole internet. It visits its own sites — every site here is a page made for this browser. Type a name in the address bar, like ajg.com, and the browser opens that site right here.

Get your own .com

You can have your own .com domain — for this browser only. Pick a name, like yourname.com, and it becomes a real address here: anyone using this browser can type it in and land on your page. These domains live inside this browser, not on the regular internet.
